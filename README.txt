# ⚡ BurpMobile

Herramienta de pruebas web para dispositivos Android. Diseñada para enviar solicitudes HTTP, codificar/decodificar Base64 y revisar encabezados de seguridad en sitios propios o con autorización.

## ⚠️ Aviso importante
Esta aplicación está destinada **únicamente para pruebas en sistemas propios o con autorización escrita**. El uso indebido es responsabilidad del usuario.

## ✅ Funciones
- 🔌 **HTTP Tester / Repeater** — Envía solicitudes GET, POST, PUT, DELETE
- 🔐 **Decoder** — Codifica y decodifica Base64
- 🛡️ **Scanner** — Revisa encabezados de seguridad de una URL
